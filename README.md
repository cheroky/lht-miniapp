# La Hora del Te – mini app de Telegram

Página sencilla que se abre dentro de Telegram desde el botón **Programas** del bot del canal @lhtnooficial.
Muestra los programas LHT y LHdD ya publicados, el más nuevo primero, con botón para escucharlos (reproductor de SoundCloud), abrirlos en SoundCloud o verlos en el canal.

- Todo está en `index.html` (HTML + CSS + JS, sin servidor).
- Usa `telegram-web-app.js` y los colores del tema de Telegram (claro/oscuro).
- Se publica gratis con GitHub Pages: https://cheroky.github.io/lht-miniapp/

Por ahora la lista es fija: para agregar programas nuevos hay que regenerar `index.html`.
